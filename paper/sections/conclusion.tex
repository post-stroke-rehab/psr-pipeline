\section{Conclusion}

This paper presents \repo\ as a software research framework for sEMG-based finger-intent prediction in post-stroke neurorehabilitation. The contribution is not a new standalone network, but a reproducible experimental program that makes ingestion, preprocessing, feature extraction, tensor adaptation, architecture comparison, transfer learning, and deployment-screening utilities explicit and reusable.

The evaluation now tells a clearer story. The project begins with three direct model families, LSTM, CNN, and GNN, whose baseline results show complementary strengths rather than a trivial winner. It then advances through optimized CNN students and internal ResNet teachers, where CNN-Large becomes the strongest committed artifact, and through transfer-learning experiments that help the CNN branch but not the LSTM branch consistently. Distillation, threshold tuning, and latency benchmarking now exist as concrete deployment-facing pathways, but they still need the same artifact completeness as the direct benchmark path. The main remaining gap is therefore not framing. It is evidence: distilled-student result packs, Raspberry Pi 5 timing validation, and broader robustness studies that can carry this software paper toward a fully supported deployment study later.
