# Notebooks

- `retrain_cnn_micro_4ch_colab.ipynb` is the maintained four-channel
  preprocessing and retraining notebook.
- `legacy/gnn_colab.ipynb` is the original exploratory GNN notebook retained
  for provenance. The maintained GNN implementation is `models/gnn.py`.
- Additional exploratory preprocessing and visualization notebooks remain near
  the code or data area they investigate. They are not required for the
  command-line reproduction path documented in `docs/REPRODUCIBILITY.md`.
